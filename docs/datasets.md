# Dataset provenance, licensing and limitations

## Sources used by this implementation

The index is populated by `python -m bugdiag.ingest`; this repository ships no defect records. The adapter pages current public issue-tracker APIs, retains the source key/URL, and imports resolved or closed records only. Each run is bounded by `--limit` for each selected source. The default Apache JQL selects resolved issues from Lucene, Hadoop and Spark; change `APACHE_JIRA_JQL` to choose other public Apache projects.

| Source | Provenance and adapter | License treatment in the index | Limitations |
| --- | --- | --- | --- |
| Mozilla | Public Mozilla Bugzilla REST API; issue key and fields retrieved from `https://bugzilla.mozilla.org/rest/bug`; references use `https://bugzilla.mozilla.org/show_bug.cgi?id=…`. The [Mozilla Bugzilla REST overview](https://wiki.mozilla.org/Bugzilla%3AREST_API) documents public-data calls. | No dataset-wide license for issue text was verified. Stored as `Public tracker record; issue-text license not verified per item`; original URLs are retained. | Bugzilla access controls omit private reports, but a formerly private issue may later become public. Public reports may still include personal or security-sensitive text. Email-shaped values are redacted; this is not a complete privacy scrub. |
| Apache | Public Apache Jira REST API at `https://issues.apache.org/jira/rest/api/2/search`, using JQL and paginated fields; original links use `https://issues.apache.org/jira/browse/{key}`. See [Atlassian Jira Data Center search API](https://developer.atlassian.com/server/jira/platform/rest/v11002/api-group-search/). | No uniform license for issue text across Apache projects was verified. Repository source-code licenses do not establish issue-description licensing. Stored as `Public tracker record; project issue-text license not verified per item`. | The default selects only Lucene, Hadoop and Spark; field schema and anonymous access can change. Use the project’s own terms and policies for any reuse decision. |
| Eclipse | Public Eclipse Bugzilla REST API at `https://bugs.eclipse.org/bugs/rest/bug`; source references use the Eclipse Bugzilla issue URL. This does **not** assert the license of each record. Eclipse project code often uses EPL, but the project code license must not be assumed to cover tracker text. | The historic Bugzilla host/available records can change as projects migrate. The Eclipse Foundation separately publishes [Scava / Eclipse Open Datasets](https://download.eclipse.org/scava/projects/) containing issue-tracking extracts and states those datasets use CC BY-SA 4.0. That license applies to those named extracts under their published terms; the live Bugzilla adapter above does not download or relicense Scava files.

## Rights and privacy handling

Public access is not equivalent to permission for arbitrary redistribution. Project-specific terms, tracker terms, contributor rights, privacy requirements and any applicable licenses must be reviewed before bulk redistribution or training use. The UI links users back to the original issue rather than presenting this index as an authoritative copy. Records contain a conservative license status to make unresolved rights visible. Email-shaped strings are redacted before indexing; no reporter name, comments or attachments are imported. Other identifying details or sensitive technical content may remain in public descriptions.

Mozilla documents that security-sensitive bugs can remain private until public disclosure ([Mozilla security bug process](https://firefox-source-docs.mozilla.org/bug-mgmt/processes/fixing-security-bugs.html)). This adapter requests only public search results, but a report can change visibility over time. For takedown or source deletion workflows, operators should re-fetch source records and delete the corresponding indexed row when access or permission is withdrawn.

## Reproducibility

For a research or operational run, retain externally (not in this starter repository): date/time, adapter version, source URL, exact JQL and project list, per-source fetched/indexed/unchanged counts, model identifier/revision and configuration. This implementation stores `dataset_name`, source, source key, URL, ingestion timestamp and content hash. It does not archive API payloads, comments, source user identities or licenses it cannot verify.
